# 颱風觀測站 · Cyclone Atlas

透過衛星雲圖、颱風路徑與全球風場，探索天氣系統的變化。介面使用繁體中文，適合想觀察颱風、比較預報或查看不同高度風場的使用者。

[開啟網站](https://cyclone-atlas-one.vercel.app/) · [衛星觀測](https://cyclone-atlas-one.vercel.app/) · [全球風場](https://cyclone-atlas-one.vercel.app/wind) · [雷達回波](https://cyclone-atlas-one.vercel.app/radar)

## 衛星觀測

### 選擇雲圖模式

- **自動**：依地圖中心的位置與觀測時間，切換日間真實色和夜間紅外線。
- **真實色**：適合白天觀察雲層形狀；夜間區域可能偏暗。
- **黑白**：紅外線雲圖，可在日夜查看雲系。
- **OTT 強化**：以色階凸顯不同亮溫的雲頂。顏色不是雲的真實顏色，也不直接代表雨量或風速。

在 OTT 模式點選地圖，可查看位置與**亮溫估計值**。此數值由影像編碼估計，不是原始衛星的精確定標溫度；有雲時近似雲頂亮溫，晴空時可能反映地表亮溫。

### 查看時間與動畫

使用時間軸選擇影像，或展開設定選擇日期、時間、動畫起始點與播放間隔。頁面會標示影像的觀測時間與時區；它不是預報時間。最新影像會自動更新，歷史可用範圍依資料來源而定。

### 觀察颱風

- 查看日本氣象廳（JMA）的最新分析位置與官方預報路徑。
- 查看目前颱風已走過的歷史路徑，不是往年的颱風列表。
- 開啟或關閉各模式路徑，比較不同預報結果。系集路徑表示不同成員的預測，不是同時存在多個颱風。
- 點選預報位置查看時間、經緯度，以及來源有提供的風速、氣壓與風圈資料。缺少的欄位不會以其他來源補成該模式的預報。

**風圈與預報圈不同：**黃色表示烈風圈（30 節以上），紅色表示暴風圈（50 節以上）；白色虛線預報圈表示預報中心位置的不確定性，並不是風圈。暴風警戒域包含預報不確定性，也不表示整個區域目前都有暴風。

### 下載雲圖

調整地圖位置、範圍與雲圖模式後，按下載按鈕儲存圖片。圖片包含品牌標誌、資料時間與來源標示。匯出尺寸與放大倍率不會增加衛星原本沒有的細節。

## 全球風場

### 選擇模式與高度

選擇預報模式、風場高度、風速單位和區域。已接入的公開原始風場包含 GFS、ECMWF IFS、AIFS、GEFS、AIGEFS、ICON、GEPS 與 JMA GSM；實際可選項目、預報長度和資料間隔以頁面顯示為準。

- **10 公尺／100 公尺**：表示距地面的高度。
- **百帕（hPa）**：表示氣壓層，不是固定海拔；高空格點可能位於地形下方。
- **未來預報**：查看模式預測。
- **歷史再分析**：查看 ERA5 重建風場，不是直接觀測，也不是當時發布的預報；最新資料存在延遲。

### 閱讀風場

顏色代表風速，請對照色條。流動粒子顯示風吹向哪裡，其播放速度經過加速，不代表空氣的實際移動速度。

點選地圖可查看風速、來向、位置及資料時間；關閉資訊視窗後，位置標記會同步移除。缺測格點不代表無風。地圖上的 JMA 颱風路徑與風圈採最新官方資料，不會隨風場歷史回放一起回溯。

### 播放動畫

展開時間設定，選擇動畫起始和結束時間，再按播放。動畫依模式實際提供的資料時刻前進；不同模式的時間間隔可能不同。切換影格前會先準備資料，來源較慢或暫時缺資料時仍可能需要等待。

手機版將模式設定與進階時間設定收合，保留更多地圖空間。需要調整時再展開即可。

## 地圖操作

- 電腦：拖曳移動、滾輪縮放，或使用「＋／－」。
- 手機：單指拖曳、雙指縮放；地圖保持北方朝上。
- 可移動到其他地區，但衛星雲圖目前以向日葵衛星可觀測範圍為限；空白區域不代表晴空。

## 資料來源與使用須知

衛星資料來自 NICT 向日葵衛星服務；官方颱風資訊來自日本氣象廳。模式資料由 ECMWF、NOAA、DWD、ECCC、FNMOC、Google Weather Lab 等來源提供；歷史風場使用公開 ARCO-ERA5 資料。各圖層的時間、解析度與更新頻率可能不同，請閱讀頁面標示。

本網站提供天氣觀察與預報比較，不保證來源持續可用或預報完全準確。防災、出行與停班停課等決策，請以[中央氣象署](https://www.cwa.gov.tw/)及所在地官方公告為準。

- [NICT 向日葵衛星](https://himawari8.nict.go.jp/)
- [日本氣象廳颱風資訊](https://www.jma.go.jp/bosai/map.html#contents=typhoon)
- [ECMWF 開放資料](https://www.ecmwf.int/en/forecasts/datasets/open-data)

## 全球天氣圖

從頁首的「天氣圖」進入新頁面，可查看：

- **相對濕度**：以百分比顯示所選氣壓層的濕度。
- **位勢高度**：以位勢公尺（gpm）顯示，並可開啟每 60 gpm 的等高線。
- **氣溫**：以攝氏度顯示所選氣壓層的溫度。

提供 GFS、ECMWF IFS、AIFS Single、GEFS 平均、AIGEFS 平均、GEPS 平均、ICON Global、JMA GSM，以及 ERA5 歷史再分析。可選擇 925、850、700、500、300、250、200 hPa；JMA 相對濕度僅提供至 300 hPa。尚無已接入公開原始場的模式會列出，但不開放選取。

點選地圖可查看格點內插數值；下方可調整預報時效、播放動畫，以及切換臺灣時間或 UTC。ERA5 可選最近三個月的日期（最新約延遲六天）。手機版可收合設定和時間控制，保留地圖空間。

### 如何理解數據

- 所有圖層均從提供機構的原始 GRIB2／Zarr 資料產生，不使用其他模式代替缺測資料。
- AIFS、AIGEFS 與 ERA5 的相對濕度由原始比濕、氣溫及氣壓診斷，採相對於液態水的定義，與冰相／混合相相對濕度可能不同。AIGEFS 使用平均場診斷，不是各成員相對濕度的平均。
- 系集平均會平滑局部極值；圖上數值不是實測值。高空圖層可能包含地形以下的外推值。
- ICON 使用官方網格索引映射至 0.25° 顯示格點；放大畫面不會增加原始資料解析度。
- 動畫逐張讀取原生預報時效，資料較慢時會保留前一張及其有效時間，不會把舊資料標成新時間。

### 複合天氣圖與單點預報

「天氣圖」新增 6h／24h 降水、起報累計降水（IFS／AIFS）、2m 氣溫、總雲量、海平面氣壓、CAPE（IFS 最不穩定氣塊／GFS 地面氣塊）。表面產品目前支援 GFS、IFS、AIFS；其餘模式提供已驗證的高空濕度、氣溫及高度場，不以其他模式替代缺少欄位。

可選擇「6h 降水＋925hPa 風場」、「850hPa 風場＋500hPa 高度場」、「2m 氣溫＋500hPa 高度場」。點選地圖後，在 GFS／IFS／AIFS 每六小時時效可按「取得此點六要素」，按需載入氣溫、濕度、風、氣壓、降水、雲量。數值為模式格點內插，不是測站觀測。

降水先驗證原始 GRIB 累積起止時段，再差分或合計，不混用起報。GFS 起報總累計需要多張全球原始場，為節省傳輸未開放，仍提供 6h／24h。預報採 CDN 快取、解碼場有界快取、僅预取下一張動畫；單點六要素不自動載入。公開資料不等於主機傳輸沒有成本。

附圖中的 SD3、TD、WNC 等產品名稱尚無已驗證公開原始接口，不冒稱支援。颱風路徑及警報圖層沿用衛星頁面；預報誤差統計需要回測資料，沒有用系集離散度替代實際誤差。

## 雷達回波與垂直剖面

雷達回波頁面提供關島周邊 NOAA MRMS 多高度原始回波，以及臺灣 CWA、日本 JMA 平面觀測。只有關島來源目前具備 33 個原生海拔高度層（0.5–19 公里），不會把平面回波拉高假裝成立體觀測。

1. 選擇關島 MRMS，按「繪製剖面線」，在地圖依序點選 A、B。完成後可拖動端點。
2. 以 A → B 判斷左右，切換「從左側看／從右側看」。換側反轉畫面中的端點順序，不改變觀測值；也可以交換 A、B。
3. 切換平面或立體剖面，在剖面上移動游標／輕觸查看距離、原生高度層與 dBZ。地圖會同步標示所指位置。
4. 選擇地圖高度切片、觀測時間及播放間隔。手機可以收合剖面面板，保留地圖空間。

地圖採樣為 0.02°，剖面使用原始 0.005° 最近格點；放大不會增加原始解析度。最低層以下保持空白，灰色為缺測，深藍為低於 0 dBZ。立體剖面只是切面的透視顯示，不是整團雲或降水的三維等值面；高度軸誇張顯示以方便閱讀。各高度層用色帶表示，不補造層間資料。

首次剖面需要取得 33 個高度層；後續使用快取並預載下一張。歷史範圍依來源保留清單，關島頁面最多列出最近 60 個觀測時間；資料過期或高度層缺漏時明確顯示狀態。臺灣回波為 dBZ，日本降水強度為 mm/h，兩者不能直接以同一數值比較。

來源：[NOAA MRMS 原始高度層](https://mrms.ncep.noaa.gov/3DRefl/GUAM/) · [MRMS 官方產品說明](https://www.nssl.noaa.gov/projects/mrms/)。
