# GFS 原始風場資料管線

## 已接入
- 固定來源：NOAA 公開 AWS GFS 0.25° GRIB2；免 API Key。
- 最新起報索引每十五分鐘確認；採保守五小時發布等待，最多回查三個循環。
- 依 `.idx` 精確取得 U/V；高空風另取得地面氣壓。來源必須回覆符合索引的 HTTP 206 範圍。
- 每張原始風場約 1–3 MB（欄位與高度不同），不是下載整份數百 MB 的 GRIB。
- 解碼在瀏覽器背景 Worker 執行。原始 1440×721 格點全部保留；另補一欄讓日界線無縫。
- 壓力層低於地形時以缺測遮罩處理，不填零風。
- 前 120 小時逐時，其後按原始三小時時效選最近一張，顯示真正有效時間。
- 邊緣快取不可變的起報欄位；裝置最多保留六張解碼風場，地圖平移與縮放不查詢資料源。
- 播放時先預載、解碼下一張，再推進時間。冷載入仍取決於網路，未宣稱無限流量或保證即時。
